# GoogleChromeHack

Проект для работы с Google Chrome на низком уровне. Содержит код на C++ (84.8%) и C (15.2%).

## Описание

GoogleChromeHack - это проект, который позволяет взаимодействовать с Google Chrome посредством низкоуровневого кода, написанного на C++ и C.

## Требования

- **Компилятор C++**: GCC, Clang или MSVC
- **Компилятор C**: GCC, Clang или MSVC
- **ОС**: Linux, macOS или Windows

## Инструкции по сборке

### Linux/macOS
```bash
# С использованием GCC
g++ -o hack *.cpp *.c

# С использованием Clang
clang++ -o hack *.cpp *.c
```

### Windows
```bash
# С использованием MSVC
cl.exe /Fe:hack.exe *.cpp *.c

# Или с GCC (MinGW)
g++ -o hack.exe *.cpp *.c
```

## Использование

```bash
./hack [параметры]
```
